# Maison de Beauté — Simplified Midterm Project

A beginner-friendly beauty shop built with HTML, CSS and vanilla JavaScript. No frameworks, server, database or payment processing.

## Main features
- Homepage, navigation and product categories
- Product list generated from a JavaScript array of objects
- Search, category filter and price sorting
- Product details popup
- Shopping cart with quantities and total
- Wishlist
- Browser localStorage for cart and wishlist
- Simple contact form validation (no real message is sent)
